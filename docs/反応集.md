# 掲示板反応集動画 制作ルール

イナズマイレブンの掲示板まとめ・視聴者反応集動画のフォーマット固有ルール。

---

## Remotionコンポーネントのルール

### Root.tsx
- `durationInFrames` は `audio-meta.json` の合計フレーム数から自動計算する
- FPS: `30`、解像度: `1280x720`
- `tsconfig.json` に `"resolveJsonModule": true` が必要

### MyVideo.tsx
- タイトルバーは表示しない（画像をメインにする）
- 各コメントを `<Sequence from={startFrame} durationInFrames={...}>` で順番に並べる
- **背景は約30秒（900フレーム）ごとにコメント境界で切り替える**
  - 10種類のBGコンポーネントを順番にサイクル（GoldenBokehBG → StarburstBG → AuroraBG → SakuraBG → NeonGridBG → StarZoomBG → LavaLampBG → FireworksBG → PrismBeamBG → DigitalRainBG → ループ）
  - `buildBgSegments()` が自動計算するため手動指定不要

### CommentScene.tsx のレイアウト

```
┌──────────────────────────────┐ 0px
│                              │
│     [アニメ画像]（中央・やや上）│ top:16px〜bottom:160px
│                              │
├──────────────────────────────┤
│  ███ 常時表示の半透明黒バー ███ │ 下部220px（MyVideo.tsxが描画）
│  字幕テキスト（二重縁取り）     │ ← CommentScene がフェードイン/アウト
└──────────────────────────────┘ 720px
```

- 画像: `maxWidth: 82%`、`objectFit: contain`、中央配置、`bottom: 220` まで（4セリフ間は同じ画像を表示し続ける）
- 字幕バー: `MyVideo.tsx` に常時表示の `rgba(0,0,0,0.78)` の黒バー（高さ220px）
  - `CommentScene.tsx` はグラデ背景なし・テキストのみをフェードイン/アウト
  - 3行（56px × lineHeight 1.2 × 3 ≈ 202px）が収まるよう220pxを確保
- 著作権: `MyVideo.tsx` の右上に常時表示（本編中のみ、20px、白文字黒縁）

### 字幕テキストスタイル（二重縁取り）

**フォント: `ラノベPOP v2`**（システムにインストール済みであること）
```css
fontFamily: '"ラノベPOP v2", "Noto Sans JP", sans-serif'
```

**フォントサイズ: 最大`56px`・最小`30px`（動的調整）**
- Canvas API でテキスト幅を測定し、3行以内に収まる最大サイズを自動計算
- 56px から2px刻みで下げ、`ceil(textWidth / 1176px) <= 3` を満たすサイズを採用

**行間: `lineHeight: 1.2`**（詰めて中央寄りに。`justifyContent: 'center'` でバー内縦中央に配置。1行でも3行でも常にバー中心）

**テキスト揃え: `textAlign: 'center'`**（常に中央揃え）

スピーカーごとの色:
- ずんだもん: `#FFE000`（黄）
- 四国めたん: `#FF4444`（赤）
- 春日部つむぎ: `#44AAFF`（青）
- **イントロ（isIntro: true）: `white`（白）**

**縁取り順のルール（色によって異なる）:**

| 色 | 外縁（12px） | 内縁（6px） | 文字色 |
|---|---|---|---|
| 赤・青 | 黒 | 白 | 各色 |
| **黄のみ** | **白** | **黒** | 黄 |
| **白（イントロ）** | **黒** | **黒** | 白 |

黄色だけ縁取り順を逆にする理由: 黄文字に白内縁だと境界が見えにくいため、黒を文字に近い側に置く。

縁取りの実装（3層の絶対配置スパン）:
```tsx
const isYellow = color === '#FFE000';
const outerStroke = isYellow ? 'white' : 'black';
const innerStroke = isYellow ? 'black' : (color === 'white' ? 'black' : 'white');

// 外縁（最背面）
<span style={{ position: 'absolute', color: outerStroke, WebkitTextStroke: `12px ${outerStroke}`, paintOrder: 'stroke fill' }}>
// 内縁
<span style={{ position: 'absolute', color: innerStroke, WebkitTextStroke: `6px ${innerStroke}`, paintOrder: 'stroke fill' }}>
// カラー文字（position: relative で高さ確保）
<span style={{ position: 'relative', color }}>
```

### フェードアニメーション
- フェードイン: `interpolate(frame, [0, 15], [0, 1])` = 0.5秒で一括表示
- フェードアウト: 終盤10フレームで実施
- タイプライター式は使わない

### コメント間のパディング
- `PAUSE_FRAMES = 25`（約0.8秒）を各コメントのdurationInFramesに加算

## イントロシーンのルール

**全動画の冒頭に必ず以下の3セリフを入れる。**

| # | テキスト | 話者 | SE | 画像 |
|---|---|---|---|---|
| 1 | 【ワクワクする紹介文】（下記参照） | 四国めたん（ノーマル）: `2` | `和太鼓でドドン.mp3` | `title.png` |
| 2 | 【背景・文脈の一言】（下記参照） | 四国めたん（ノーマル）: `2` | `拍子木1.mp3` | `title.png` |
| 3 | それではどうぞ！ | 四国めたん（ノーマル）: `2` | `拍子木2.mp3` | `title.png` |

- 3セリフとも `isIntro: true` を付与し、**白文字・黒縁**で表示する
- **話速: `1.1`**（本編の `1.3` より控えめ。ゆったりとした導入感を出す）
- **画像は3セリフ通じて `title.png` を表示し続ける（フェードしない）**
  - `MyVideo.tsx` でイントロ期間の Sequence として `IntroImage` コンポーネントを描画
  - `CommentScene` はイントロ時に画像を描画しない（テキストフェードのみ担当）

### 【ワクワクする紹介文】の作り方

視聴者を引き込む、具体的でワクワクする1文。以下の要素を盛り込む:
- **キャラの特徴・ニックネームを含める**（例: 「氷のストライカー」「二重人格の天才」など）
- **エピソードや文脈を絞り込む**（例: 「初登場した回」「覚醒シーン」など）
- 視聴者が「これは見たい！」と思う言い方にする

**形式例:**
> 「今回は「氷のストライカー吹雪士郎が初登場した回」の当時の反応を紹介します」
> 「今回は「豪炎寺修也のゴッドブレイズドライブ初使用シーン」の当時の反応を紹介します」

### 【背景・文脈の一言】の作り方

台本を作る前に **WebSearch で題材の背景を十分調査**し、その動画ならではの「分かってる人が書いた感」のある一文を敬語で生成する。

**ポイント:**
- 視聴者の当時の期待・驚き・感情の文脈を言語化する
- 「なぜこの回・このキャラの反応が面白いのか」が一文で伝わるようにする
- 敬語（です・ます調）で書く
- 1〜2文に収める（読み上げ時間: 3〜5秒程度）

**例（イナズマイレブン 吹雪士郎の場合）:**
> 「ストライカーの噂とは裏腹にDFとして現れ、さらに二重人格という衝撃の設定で当時の視聴者を虜にしたキャラクターです。」

### タイトル画像

- Remotionからの参照パス: `staticFile('images/title.png')`
- **動画のテーマ・主役キャラクターに合ったアニメ画像を毎回取得する**
  - 例: 吹雪士郎の台本 → 吹雪士郎のアニメスクリーンショットを取得して `title.png` として保存
  - 取得先は通常コメント画像と同じ（Fandom Wiki CDN など）
- `download-images.mjs` 内で `anime_01.png〜` と同様に取得し `public/images/title.png` として保存する

### generate-audio.mjs での定義例

```js
const INTRO_SPEAKER = 2; // 四国めたん（ノーマル）

const COMMENTS = [
  { id: 0, text: '今回は「氷のストライカー吹雪士郎が初登場した回」の当時の反応を紹介します', speaker: INTRO_SPEAKER, image: 'title.png', seFile: '和太鼓でドドン.mp3', isIntro: true },
  { id: 1, text: '【WebSearchで調査した背景・文脈の一文】', speaker: INTRO_SPEAKER, image: 'title.png', seFile: '拍子木1.mp3', isIntro: true },
  { id: 2, text: 'それではどうぞ！',                       speaker: INTRO_SPEAKER, image: 'title.png', seFile: '拍子木2.mp3', isIntro: true },
  // 以降は通常コメント（id: 3〜）
];

// synthesize() 内で isIntro に応じて話速を変える
query.speedScale = c.isIntro ? 1.1 : 1.3;
```

### CommentScene.tsx でのイントロ判定

```tsx
// comment.isIntro が true のとき:
// - 画像は描画しない（MyVideo.tsx の IntroImage が担当）
// - 白文字・黒縁を適用
const textColor   = comment.isIntro ? 'white'  : getSpeakerColor(comment.speaker);
const outerStroke = comment.isIntro ? 'black'  : (textColor === '#FFE000' ? 'white' : 'black');
const innerStroke = comment.isIntro ? 'black'  : (textColor === '#FFE000' ? 'black' : 'white');
```

### MyVideo.tsx での常時表示要素

**①常時表示の半透明黒バー（字幕エリア）**

全フレームを通じてコメント間も含めて常に表示。`CommentScene` のグラデ背景は使わない。

```tsx
<div style={{
  position: 'absolute', bottom: 0, left: 0, right: 0,
  height: 220,
  background: 'rgba(0, 0, 0, 0.78)',
  pointerEvents: 'none',
}} />
```

**②著作権表示（右上・本編中のみ）**

`useCurrentFrame()` で `introFrames` を超えたら表示。20px・白文字・`WebkitTextStroke` で黒縁（textShadowより鮮明）。

```tsx
const CopyrightOverlay: React.FC<{ introFrames: number }> = ({ introFrames: intro }) => {
  const frame = useCurrentFrame();
  if (frame < intro) return null;
  return (
    <div style={{
      position: 'absolute', top: 12, right: 16,
      color: 'white', fontSize: 20, fontWeight: 700,
      fontFamily: '"Noto Sans JP", sans-serif',
      WebkitTextStroke: '2px black',
      paintOrder: 'stroke fill',
    }}>
      ©LEVEL-5/イナズマイレブン/テレビ東京
    </div>
  );
};
```

### MyVideo.tsx でのイントロ画像実装

イントロ期間（isIntro:true の合計フレーム）は `title.png` を1枚ずっと表示し続ける。
セリフが切り替わっても画像はフェードしない（最初の15フレームで一度だけフェードイン）。

```tsx
// イントロ画像コンポーネント（フレーム0からフェードイン→ずっと表示）
const IntroImage: React.FC = () => {
  const frame = useCurrentFrame();
  const opacity = interpolate(frame, [0, 15], [0, 1], { extrapolateRight: 'clamp' });
  return (
    <AbsoluteFill>
      <div style={{
        position: 'absolute', top: 16, left: 0, right: 0, bottom: 200,
        display: 'flex', alignItems: 'center', justifyContent: 'center',
        opacity,
      }}>
        <Img
          src={staticFile('images/title.png')}
          style={{ maxWidth: '82%', maxHeight: '100%', objectFit: 'contain', borderRadius: 10, boxShadow: '0 6px 40px rgba(0,0,0,0.8)' }}
        />
      </div>
    </AbsoluteFill>
  );
};

// MyVideo 内での配置（introFrames = isIntro コメントの合計フレーム数）
{introFrames > 0 && (
  <Sequence from={0} durationInFrames={introFrames}>
    <IntroImage />
  </Sequence>
)}
```

## 画像取得のルール

- **zerochan.net は禁止**（二次創作のため）
- **実際のアニメのスクリーンショットを使う**
- 取得先: Inazuma Eleven Fandom Wiki CDN
  - API: `https://inazuma-eleven.fandom.com/api.php?action=query&prop=imageinfo&iiprop=url&format=json&titles=File:xxx`
  - 画像CDN: `https://static.wikia.nocookie.net/inazuma-eleven/images/...`
- ファイル名は `anime_01.png` のような連番で保存
- **画像は4セリフに1回切り替え（SEと同タイミング）**
  - 本編50コメントに対して必要な画像枚数: `ceil(50 / 4) = 13枚`（`anime_01.png` 〜 `anime_13.png`）
  - 各コメントの `image` フィールドは `'anime_' + String(Math.floor((id - 3) / 4) + 1).padStart(2, '0') + '.png'` で自動計算できる
  - イントロの `title.png` は別途（変更なし）

## BGMのルール

- ファイル: `public/bgm/おどれグロッケンシュピール.mp3`
- **動画の冒頭（フレーム0）から再生開始**（イントロ中も流れる）
- 動画終了まで `loop` で流し続ける
- **フェードイン: 30フレーム（1秒）で `0 → 0.12` にフェード**
- 音量: `0.12`（SEの0.15より控えめ）

### MyVideo.tsx での実装

```tsx
// Sequenceで囲まず直接配置（フレーム0から再生）
<Audio
  src={staticFile('bgm/おどれグロッケンシュピール.mp3')}
  volume={(f) => interpolate(f, [0, 30], [0, 0.12], { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' })}
  loop
/>
```

## SE（効果音）のルール

### ファイル一覧
`public/se/` に以下の4ファイルがある:
- `和太鼓でドドン.mp3`
- `拍子木1.mp3`
- `拍子木2.mp3`
- `小鼓（こつづみ）.mp3`

### 頻度ルール

**4セリフに1回**SEを鳴らす。残り3セリフは `seFile` なし（省略）。

- イントロ3セリフは従来通り毎回SE付き（和太鼓でドドン → 拍子木1 → 拍子木2）
- 本編は id が `3, 7, 11, 15, ...`（4の倍数+3）のコメントのみ `seFile` を付与

### SE種別の選び方

| コメントの性質 | 使うSE |
|---|---|
| 自信満々・断言系（「〜に決まってる」「〜はこれだ」など力強い系） | `和太鼓でドドン.mp3` |
| それ以外 | `拍子木1.mp3` → `拍子木2.mp3` → `小鼓（こつづみ）.mp3` をローテーション |

同じSEが2回連続しないようにローテーションを1つ進める。

### 音量
- **volume: `0.15`**（控えめ。音声の邪魔にならない程度）

### 実装方法
- `seFile` を持つコメントのみ `audio-meta.json` に `seFile` フィールドを含める
- `CommentScene.tsx` は `comment.seFile` が存在するときのみ `<Audio>` を追加（既存実装で対応済み）

```js
// generate-audio.mjs のコメント定義例（4つに1つだけ seFile を付与）
{ id: 3,  seFile: '和太鼓でドドン.mp3', ... },
{ id: 4,  /* seFile なし */ ... },
{ id: 5,  /* seFile なし */ ... },
{ id: 6,  /* seFile なし */ ... },
{ id: 7,  seFile: '拍子木1.mp3', ... },
{ id: 8,  /* seFile なし */ ... },
// ...
```

```tsx
// CommentScene.tsx（既存実装・変更不要）
<Audio src={staticFile(`audio/${comment.filename}`)} />
{comment.seFile && (
  <Audio src={staticFile(`se/${comment.seFile}`)} volume={0.15} />
)}
```

## 台本作成のルール

- テーマに合う掲示板スレ（2ch/5ch）や感想ブログをWebSearchで探す
- ameblo, livedoor blog, ranking.net, Yahoo!知恵袋 などが感想の宝庫
- コメントはTTS読み上げに適した形に整える（記号・絵文字・スラング除去）
- 話者を複数キャラに割り振ってテンポよく見せる（ずんだもん→四国めたん→春日部つむぎ→ループ）
- **冒頭3セリフ（イントロ）は必ず入れる**（「イントロシーンのルール」参照）
- **本編コメントは50本**（イントロ3本 + 本編50本 = 合計53セリフ）
- **声優・キャスト関連の話題は入れない**
- **当時の視聴者の反応集なので、続編・後続作品への言及は入れない**
